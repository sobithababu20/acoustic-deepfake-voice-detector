# Acoustic Deepfake and Voice Cloning Discriminator

AI-based detection of spoofed and synthetic speech using MFCC features and a CNN.

## Pipeline
Audio Input → Preprocessing → MFCC → CNN → Bonafide/Spoof

## Technologies
Python, TensorFlow, Keras, Librosa, NumPy, Streamlit

## Dataset
ASVspoof 2019 Logical Access (LA)

## Important
The included demo model is a prototype trained on a small subset for demonstration. It should not be presented as a full ASVspoof benchmark result.
